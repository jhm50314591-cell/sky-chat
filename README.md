# 모아 — 친구들끼리 쓰는 작은 소셜

다크 모드 기반의 반응형 소셜 웹앱입니다. 홈 피드, 사진/이모지 게시물, 좋아요와 댓글, 24시간 스토리와 답장, 1:1·그룹 채팅, 알림, 프로필 편집, 개인 배경 설정을 담았습니다.

## 바로 실행하기

이 폴더에서 Python 3가 설치된 컴퓨터로 아래 명령을 실행하고, 브라우저에서 `http://localhost:8000`을 여세요.

```powershell
py -m http.server 8000
```

또는 `python -m http.server 8000`을 사용할 수 있습니다. 별도 빌드 단계와 환경 변수, 데이터베이스는 필요하지 않습니다.

## 정적 호스팅에 배포하기

`moa-app-deploy.zip`의 압축을 푼 뒤 `index.html`, `style.css`, `app.js`가 웹사이트의 최상위 폴더에 오도록 파일을 업로드하세요. 빌드 명령과 환경 변수는 비워두면 됩니다. 앱은 브라우저에서 실행되는 정적 웹사이트입니다.

이 배포본은 앞서 설명한 브라우저 저장 데모입니다. URL을 친구에게 공유해도 각자의 브라우저는 서로 다른 데이터를 저장하므로, 공용 피드와 채팅을 만들려면 백엔드 연결이 먼저 필요합니다.

## 데모 사용법

- 홈에서 게시물과 스토리를 만들고, 게시물 댓글과 좋아요를 남길 수 있습니다.
- 메시지에서 친구와 1:1 대화를 시작하거나 여러 사람을 골라 그룹 대화방을 만들 수 있습니다.
- 스토리의 답장은 해당 친구와의 1:1 대화에 전달됩니다.
- 프로필 편집의 **내 데모 프로필 바꾸기**는 여러 계정 화면을 시험하기 위한 기능입니다. 친구 추가 화면에서 샘플 친구를 더 만들 수도 있습니다.
- 프로필 화면에서 다크 배경, 오로라/노을 배경, 사진 배경을 고를 수 있습니다.
- 게시물/프로필/배경 사진은 브라우저 안에서 크기를 줄인 뒤 저장합니다. 데이터는 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터 삭제 또는 다른 기기/브라우저 사용 시 데이터가 이어지지 않으며, 저장 공간 한계에 도달하면 이미지 업로드가 실패할 수 있습니다.

## 친구들과 실제로 함께 쓰기 전에

현재 구현은 **브라우저 단독 데모**입니다. 화면과 상호작용은 동작하지만, 회원가입/로그인, 기기 간 데이터 동기화, 서버 저장, 실시간 메시지, 실제 여러 사용자를 위한 접근 제어는 연결되어 있지 않습니다. 따라서 이 상태로 인터넷에 올려도 친구들이 같은 피드와 대화를 공유하지 못합니다.

실사용 배포에는 Supabase 같은 백엔드가 추가로 필요합니다. 그 구성은 프로젝트 URL과 공개 anon key를 앱에 연결하고, 서버에서 다음 데이터를 관리하는 형태입니다: 계정/프로필, 게시물/댓글/반응, 스토리/답장, 대화/메시지, 알림, 이미지 스토리지. 모든 테이블에 로그인 사용자 확인 및 그룹 가입 여부를 검사하는 RLS 정책이 필요하며, 초대제를 쓰려면 가입 허용 목록이나 초대 코드 검증도 추가해야 합니다. 비밀 service-role key는 브라우저 코드에 넣으면 안 됩니다.

이 저장소에는 아직 Supabase 환경 변수, SQL 마이그레이션, 로그인 기능이 구현되어 있지 않습니다. 현재 필요한 환경변수와 DB 설정은 **없음**이며, 데모 데이터는 브라우저별로만 저장됩니다.

## 구성 파일

- `index.html` — 앱 시작 화면
- `style.css` — 다크 테마와 모바일/데스크톱 반응형 스타일
- `app.js` — 화면 및 데모 기능, 브라우저 저장
